BrainCode is an event-driven language for exploring threshold neurons, rolling memory, and explicit outputs. Write a handler once; each normalized input sample advances its state.

01 · SIGNALS

Threshold neurons

Declare multiple neurons with different normalized thresholds, then ask each whether the current sample fires.

02 · STATE

Memory that evolves

Keep a bounded rolling window, query recent values, and update persistent state with allowlisted expressions.

Make results explicit

Emit named signals or decisions for each sample. The command-line runner can return one JSON record per input.

Read the program

A motor-intent signal, step by step.

This example demonstrates language mechanics on made-up normalized values. It is not a brain decoder or a biological model.

examples/simple_perceiver.brainBrainCode
# Model a simple motor-intent signal using thresholds and a rolling window.
brain MotorIntent:
  input eeg: Signal
  memory recent(capacity=3)
  neuron permissive(threshold=0.4)
  neuron strict(threshold=0.8)
  state confidence = 0.1
  state baseline = 0.2

  on eeg as sample:
    let active = permissive.fire(sample)
    let high_confidence = strict.fire(sample)
    recent.store(active)
    confidence = learn(confidence, from: recent.mean(), rate: 0.5)
    baseline = max(baseline, sample * 0.5)
    if recent.ratio() and active and not high_confidence:
      decide "motor-intent"
      emit "confidence", confidence
    else:
      emit "baseline", baseline
Example output

One result for each sample.

Run with 0.6, 0.9, and 0.1. Values below are from the interpreter's JSON output.

How it works: The first two samples cross the permissive threshold, so the rolling response ratio is high. On sample one, the strict neuron does not fire, and the handler emits the decision. On later samples, the condition is false and the else branch emits the baseline.

Get the source

Clone the BrainCode repository or download the example above.

Provide samples

From the repository folder, pass normalized values from 0 to 1:

python braincode.py examples/simple_perceiver.brain --signal 0.6 --signal 0.9 --signal 0.1 --json

Inspect the records

Each JSON line includes the input, current states, decision (if any), and explicit outputs.

Scope and safety: BrainCode is a lightweight simulation language, not a hardware driver, validated BCI, or clinical tool. Its interpreter evaluates expressions through a restricted operator and function allowlist; BrainCode source is not executed as Python. Example thresholds, input values, and decisions are illustrative only.
