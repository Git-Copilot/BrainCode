Language reference

The building blocks.

Use indentation or braces for blocks. Programs receive one normalized sample at a time and retain declared state between samples.

Program setup

brain <name>: input <name>: Signal neuron <name>(threshold=<0..1>) memory <name>(capacity=<count>)

State and events

state <name> = <number> on <input> as <sample>: let <name> = <expression> <state> = <expression>

Control and output

if <condition>: … else: … decide "<label>" emit "<label>", <expression> recent.mean() · recent.ratio()

Expressions

+ - * / % · comparisons and · or · not abs · min · max · round learn(state, from: value, rate: rate)
Run locally

Use the Python interpreter.

The website edits and downloads source; it does not execute BrainCode in the browser.

Download your program, clone the repository, then run the interpreter with normalized input values from 0 to 1:

python braincode.py <your-program.brain> --signal <value> --json

Use additional --signal arguments to process a sequence. Each JSON output record includes the input, persistent states, any decision, and explicitly emitted signals.

Scope and safety: BrainCode is a lightweight simulation language, not a hardware driver, validated BCI, or clinical tool. Its interpreter evaluates expressions through a restricted operator and function allowlist; BrainCode source is not executed as Python. User-defined thresholds and inputs are simulation parameters, not biological measurements.
