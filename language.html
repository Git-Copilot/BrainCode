Language reference

The building blocks.

EEG programs declare their sampling contract up front. The previous normalized-signal simulator is still supported.

EEG program setup

brain <name>: input eeg: EEG sample_rate 256Hz window 256 samples step 128 samples channels C3, C4

Features and events

bandpower(frame, "C3", 8, 13) rms(frame, "C3") · mean(frame, "C3") line_length(frame, "C3") peak_to_peak(frame, "C3") state <name> = <number>

Control and output

on eeg as frame: let <name> = <expression> if <condition>: … else: … decide "<intent-label>" emit "<feature-name>", <value>

Signal simulation compatibility

input <name>: Signal neuron <name>(threshold=<0..1>) memory <name>(capacity=<count>) recent.mean() · recent.ratio() learn(state, from: value, rate: rate)

Expressions

+ - * / % · comparisons and · or · not abs · min · max · round if / else blocks · indentation or braces
Run locally

Replay EEG locally.

The website edits source; the Python interpreter processes CSV windows locally and does not upload recordings.

Download your program, clone the repository, and provide a CSV whose headers match the declared channel names:

python braincode.py examples/motor_imagery.brain --csv RECORDING.csv --json

Each output record includes its sample/time offset, persistent states, optional intent decision, and explicitly emitted feature values. Repeated --signal inputs remain available for the lightweight simulation mode.

Scope and safety: EEG support is offline CSV replay for prototyping, not live acquisition, a validated classifier, medical interpretation, or a hardware driver. Decisions are emitted as data only; the interpreter does not stimulate tissue or control devices. BrainCode uses an allowlisted expression evaluator, not Python execution. Validate datasets, calibration, latency, and safety independently.
