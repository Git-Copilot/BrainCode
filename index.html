Language basics

sample name volume=50 uL signal=0.72
Declares a simulated sample and its normalized tracer signal.

reagent name volume=200 uL
Declares a liquid inventory. Optional signal= lets you model tracer dilution.

step name: groups ordered operations. Use transfer, mix, incubate, then measure signal and report.

Samples & reagentsDeclare starting volumes and a normalized simulation-only signal. Units support microliters (uL) and milliliters (mL).
Checked operationsTransfers conserve volume, prevent overdraw, and blend the simulated tracer value. Steps run in the order written.
Measurements & reportsMeasure the simulated signal, name the result, and report it. No network, lab equipment, or external service is involved.

This is an educational language prototype, not a validated biological model or a source of laboratory procedures. Incubation and mixing are logged only; they do not model reaction kinetics, safety, biological outcomes, or real-world protocol suitability. Never use its output to run an experiment or control lab equipment.
